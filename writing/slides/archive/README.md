# slides/archive/

**Frozen final PDFs** of the slides as presented at specific venues. These are records:
once dropped here they are never edited or regenerated, preserving exactly what was
shown regardless of whether the current `.tex` sources would still recompile identically
(fonts, TeXLive version, and upstream data drift over time).

**Naming:** `YYYY-MM-<occasion>.pdf`, so files sort chronologically and self-describe.

```
2026-01-assa.pdf
2026-06-nber-summer.pdf
```

Tracked in git (a tracked PDF here is a deliberate snapshot). The *living* compiled
`template-slides.pdf` in the parent folder is the current build; these are the archived
past.
