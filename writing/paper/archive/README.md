# paper/archive/

**Frozen final PDFs** of the paper at meaningful milestones — a submission, a
circulated draft, a specific version. These are records: once dropped here, they are
never edited or regenerated. Keeping them means "this is exactly what I sent / posted,"
independent of whether the current `.tex` sources would still recompile to the same
thing.

**Naming:** `YYYY-MM-<occasion>.pdf`, so files sort chronologically and self-describe.

```
2026-03-jpe-submission.pdf
2026-09-revision-r1.pdf
```

Tracked in git (a tracked PDF here is a deliberate snapshot). The *living* compiled
`template-*.pdf` in the parent folder is the current build; these are the archived past.
